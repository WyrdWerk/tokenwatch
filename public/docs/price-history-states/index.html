Every state the daily-snapshot chart can render, on the real component and the real stylesheet.

Why each state exists

Price history starts with the first daily snapshot, so a new model legitimately has no data. A missing day is a day with no snapshot, not a $0 price. A flat series is a real, unchanged price — not a broken axis. Each of those must look different from a failure.
