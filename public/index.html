Frequently asked questions

What is the cheapest LLM API right now?

TokenWatch ranks {{modelCount}} models across {{providerCount}} providers by effective cost at your usage mix. The cheapest model depends on your workload — use the calculator to find the lowest-cost option for your specific input, cached-input, and output mix.

How do I calculate LLM API cost for an agentic workload?

Enter your total token volume and the percentage split across input, cached input, and output. TokenWatch computes the cost per offering using each provider per-million-token rates, including cache-read discounts and one-time cache-write costs.

Which LLM providers have zero data retention (ZDR)?

TokenWatch tags providers that do not retain your prompts. Use the ZDR-only filter to restrict results to zero-data-retention offerings.

How does prompt caching reduce LLM API cost?

Cached input tokens are billed at a discounted rate. TokenWatch applies each provider cache-read price to your cached-input percentage, so you can see the real cost of repeated system prompts and stable context.
