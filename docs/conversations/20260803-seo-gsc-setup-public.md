## What TokenWatch is

[TokenWatch](https://tokenwatch.wyrdwerk.com) is a zero-dependency, pure-Node-ESM static site that compares pay-as-you-go LLM inference pricing across ~75 providers and ~994 text models, plus separate image and video generation catalogs. Deployed to Cloudflare Pages with 2-hourly CI/CD refresh. The core innovation: OpenRouter's `/endpoints` API is de-aggregated so each backend (Fireworks, Together, Novita, SiliconFlow…) becomes its own row with its own pricing, rather than one generic "OpenRouter" row.

---

## The headline change

The previous headline — "Compare pay-as-you-go LLM inference pricing across providers" — was outdated. The site now does far more: budget mode, agentic presets, ZDR filtering, quality benchmarks, blended $/M, and image/video catalogs.

After researching the competitive landscape (BenchLM, LLMCalcs, LLMCostHub, AI Model Matrix — all of which position by **workload**: agent runs, coding agent, RAG), the user chose **Option B** for the H1:

> **"Know what your AI actually costs before the bill arrives"**

The title tag is keyword-rich: `LLM API Pricing Comparison — Compare 994 Models Across 75 Providers | TokenWatch`.

## Quick-win SEO fixes

Applied to all three HTML pages (`index.html`, `image.html`, `video.html`):

- **Keyword-targeted titles + meta descriptions** per page (text / image / video)
- **Canonical tags** (self-referencing)
- **Open Graph**: `og:site_name`, `og:image` (1200×630), `og:image:width/height`
- **Twitter Card**: `summary_large_image` + `twitter:image`
- **Real favicon** (`favicon.svg`) + `apple-touch-icon`
- **JSON-LD structured data** (validated): `WebSite` (with SearchAction), `SoftwareApplication`, `FAQPage`, `BreadcrumbList`
- **Visible FAQ section** (4 questions matching the FAQPage schema)
- **`<noscript>` fallback** with links

## Crawlability fix

The site is a client-side-rendered SPA — all content loads from `pricing.json` via `fetch()`, so Google's crawler saw an empty table in the raw HTML. Fixed with **build-time static generation**:

- `scripts/generate-seo.mjs` server-renders the **25 cheapest models** (by effective cost at the agentic mix 2.5/97/0.5) into `index.html` as a real HTML table — Google now sees pricing content in the raw HTML.
- Wired as `npm run seo`.
- Also generates `sitemap.xml` (with `lastmod` from `generated_at`) and `robots.txt`.

## noindex for raw data

Added `X-Robots-Tag: noindex` to `_headers` for `/api/*`, `pricing.json`, `image-pricing.json`, `video-pricing.json`, `performance.json` — so raw data files don't compete with the HTML pages in search results.

## Google Search Console setup

1. Added `tokenwatch.wyrdwerk.com` as a **Domain property** (verified via Cloudflare one-click).
2. **Sitemap submission**: initially failed with "Invalid sitemap address" when entering just the path `sitemap.xml`. The fix was entering the **full URL** `https://tokenwatch.wyrdwerk.com/sitemap.xml`.
3. **Indexing**: the homepage was already indexed. `/image` and `/video` were queued for indexing.

## Duplication bug fix

`generate-seo.mjs` was **not idempotent** — it checked for a placeholder that was never added, so every run re-inserted the "Cheapest LLM API models" table before `</main>`, duplicating the FAQ + models sections. Fixed by checking for an existing `class="seo-models"` section and **replacing** it via regex instead of re-inserting. Verified idempotent across 3 runs.
